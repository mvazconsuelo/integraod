# Alcance del producto

Cuatro secciones: **Inicio** (crear presupuesto, registrar cobro, ver pendientes, y dos números: cobrado y por cobrar), **Actividad** (historial en frases, presupuestos y cobros), **Control** (todas las métricas, cada una con su definición) y **Contactos** (+ Configuración en el menú). Después de crear un presupuesto, el cobro se define en la misma pantalla (con link, en efectivo o más tarde).
Contactos: lista con nombre completo y teléfono; se cargan al crear el presupuesto y quedan guardados. **Enviar por WhatsApp** abre el chat con el mensaje listo (y, si se quiere, el link para pagar el anticipo); el PDF se adjunta a mano.
Fuera de alcance: agenda, historias clínicas, envío automático de WhatsApp, ERP/CRM, integración con sistemas clínicos.

Pendiente / posterior: importación CSV de cancelaciones, ajuste explícito de saldo negativo, multi-clínica y usuarios.
